# 🧠 Rayyan AI for Screening Articles

Rayyan is a free, AI-enhanced web platform specifically designed to streamline the **screening phase** of systematic reviews. Whether you're working solo or as part of a team, Rayyan saves time and improves transparency and reproducibility.

---

## 🚀 Key Features of Rayyan AI

| Feature                         | Description |
|----------------------------------|-------------|
| **Blind Screening Mode**         | Prevents bias by hiding other reviewers’ decisions until screening is complete. |
| **Conflict Resolution Panel**    | Highlights conflicting inclusion/exclusion decisions and offers tools for resolution. |
| **AI-Powered Ranking**           | Learns from your screening decisions to prioritize articles likely to be included. |
| **Custom Tags & Filtering**      | Tag articles (e.g., "Wrong intervention", "Review paper") and filter easily. |
| **Notes Field per Article**      | Add justifications or reviewer comments for every decision. |
| **Bulk Actions**                 | Include, exclude, or tag multiple articles at once. |
| **Mobile & Tablet Friendly**     | Fully usable on mobile browsers for on-the-go screening. |
| **Team Collaboration Tools**     | Invite collaborators, assign roles, and track screening progress. |
| **Search and Highlight Keywords**| Use search bar to locate specific terms or highlight your criteria. |
| **Deduplication Engine**         | Automatically detects and helps you merge or delete duplicate references. |

---

## 🛠️ Prerequisites

- Exported results from databases like PubMed, Scopus, or Embase (`.ris`, `.bib`, or `.csv`)
- Defined inclusion and exclusion criteria
- Optional: PRISMA checklist for documentation

---

## 📋 Use Case Workflow

1. Import search results from databases
2. Blind screen with inclusion/exclusion logic
3. Tag reasons for inclusion/exclusion
4. AI ranks high-priority articles
5. Resolve reviewer conflicts
6. Export final list for full-text review or PRISMA reporting

---

## 📊 Dashboard Analytics

Rayyan provides basic analytics like:

- Number of articles screened
- Reviewer agreement percentage
- Top inclusion/exclusion tags
- Status summaries (Included, Excluded, Undecided)

---

## 💬 Collaboration Features

- Assign reviewers to specific articles
- Enable real-time screening across devices
- Email notifications for task progress
- Transparent audit trail of decisions
