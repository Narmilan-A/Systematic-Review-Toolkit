# Paperpile PDF Collection and Organization

## Step 1: Import References
- Import the exported `.RIS` or `.BibTeX` file from Rayyan
- Use the Paperpile Chrome extension or web interface

## Step 2: Integration with Google Drive
- Automatically sync all PDFs to a Google Drive folder
- Setup folder-based organization (e.g., by year, topic, inclusion status)

## Step 3: University Proxy Access
- Enable your university’s library proxy in Paperpile settings
- Helps access institutional subscriptions for paywalled content

## Step 4: Finding Full-Text PDFs
- Use built-in PDF finder (crossref, arXiv, publisher APIs)
- Manually upload PDFs if not found automatically
- Use tools like Unpaywall or Library Genesis (if allowed)

## Step 5: Bulk PDF Download
- Export PDFs to local folder using Google Drive sync or zip export
- Rename or tag them for SciSpace processing
