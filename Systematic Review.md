# Systematic Review Process Guide

## Overview

This document outlines the steps for conducting a systematic literature review using PRISMA guidelines, from search strategy to reporting.

## Steps

### 1. Define the Research Question
Use the PICO/PECO framework to formulate your question.

### 2. Develop the Search Strategy
Identify databases and keywords. Example: PubMed, Scopus, Google Scholar.

### 3. Run the Search and Export Results
Export references in `.bib` or `.ris` format.
